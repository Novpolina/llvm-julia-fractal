# Динамический фрактал Жюлиа на LLVM

Учебный проект для курса по LLVM: генерация кадров динамического множества
Жюлиа с выводом через минимальный интерфейс `sim.h`.
Новикова Полина, Б01-307 (Yadro), МФТИ


## Идея

Для каждой точки комплексной плоскости многократно вычисляется

```text
z(n + 1) = z(n)^2 + c.
```

Число итераций до выхода за окружность радиуса 2 задаёт цвет точки. Параметр
`c` и палитра медленно изменяются, поэтому геометрия и цвет фрактала
анимируются.

## Зависимости

Для Ubuntu или WSL:

```bash
sudo apt update
sudo apt install clang llvm make libsdl2-dev
```

## Сборка и запуск

```bash
make
./julia
```

## Проверка без графического окна

```bash
make test
```

Тест вычисляет два полных кадра, проверяет координаты каждого пикселя и число
операций рисования.

Сохранить первый кадр без открытия SDL-окна можно так:

```bash
make preview
```

Команда создаст переносимое изображение `preview.ppm`.

## Генерация LLVM IR

```bash
make ir
```

Будут созданы:

- `app_O2.ll` — оптимизация `-O2`;
- `app_Os.ll` — оптимизация `-Os`.


## Структура

```text
app.c                 вычисление и отрисовка кадра
app_O2.ll             оптимизированный LLVM IR логического модуля
app_Os.ll             компактный вариант LLVM IR
sim.h                 графический интерфейс
sim.c                 реализация интерфейса через SDL2
start.c               запуск приложения
tests/headless_sim.c  smoke-тест без SDL
tests/frame_dump.c    сохранение первого кадра без SDL
Makefile               команды сборки и генерации IR
```
